# Unit 5 Reflection: Introduction to CSS

## Lesson 1 - What is CSS?
This lesson introduced the fundamental purpose of CSS and its role in web development. Before learning this, I thought of HTML as the sole tool for building web pages, but now I understand that CSS separates content from design, making websites more maintainable and visually appealing. 

## Lesson 2 - Basic CSS Properties: Color, Font, and More
Here, I explored core CSS properties like `color`, `font-family`, `font-size`, and `background-color`. practicing with different combinations helped me understand browser compatibility better. The hands-on exercises made me realize how small style changes can effectivrly affect a webpage's looking

## Lesson 3 - Inline, Internal, and External CSS
This lesson clarified the three methods of applying CSS:
- **Inline styles**: Quick but hard to maintain
- **Internal stylesheets**: Useful for single-page projects via `<style>` tags.
- **External stylesheets**: for multi-page sites

This unit transformed how I view web design—from static HTML pages to dynamic, styled experiences.
