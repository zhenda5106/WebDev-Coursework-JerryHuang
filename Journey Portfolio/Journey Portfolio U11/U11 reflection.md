# My Learning Experience in Web Design: A Look Back

## Initial Impressions and Growth
I was eager yet nervous when I first started learning web design. I didn't know if I could master the technical skills of coding, such as HTML, CSS, and JavaScript(i did not really got what are these three things do in a web design), and questioned if I had the capacity to catch the rationale that goes with coding or make mistakes that would destroy my pages. However, I wanted to create good and functional websites that could possibly solve real problems. My ability and confidence gradually enhanced over time—I now design web sites with curiosity and problem-solving attitude. 

## Challenges Faced
The most challenging aspects were the nuances of CSS layout and JavaScript functionality. Debugging and responsive design also needed some learning. i used some extra resources from internet to help me completing the couese better for ex.: online tutorials, MDN Web Docs and coding sandboxes assisted with learning in practice.

## Design Thinking Process
The design thinking process impacted me deeply by encouraging user empathy and iterative testing. For example, in the U10 code challenge, for editing my client page about cats, i add a button which will popup a cat graph after the client click on it, i think this is kind of intriging and add the interactivity of my web.

## Incorporation of UN Global Goals
 I integrated these goals by creating websites(viewing websites about UN global goals as well) that raise social issue awareness, such as climate change, and providing content for everyone regardless of ability.Let people now how important these goals are

## Accessibility Considerations
Accessibility is necessary as it enables all users, including people with disabilities, to visit and use websites. I employed accessibility features like semantic HTML, image alternative text, and good color contrast.these features let my website can be viewed by more people.

## Implementing Best Practices
I learned best practices such as writing clean, semantic code, optimizing page load speed, and mobile-first development. Adhering to these best practices made my websites simpler to maintain, faster, and more accessible, which ultimately translated to improved user satisfaction and engagement.

## Feedback and Improvement
I got criticism from my peers and instructors that helped me to make my layouts more refined, improve on color choices, and address usability errors, how to arrangement the "boxes". I utilized criticism as a tool for growth, reviewing my projects again to implement updates that improved the overall user experience.

## Personal Design Style
My own design style has evolved to prioritize simplicity, readability, and user-centered arrangements. Initially, I described more flashing effects, but now I like clean typography, clear navigation, and well-applied white space to create a pleasant and user-friendly experience.

## Highlights and Deltas
One of the best things about this course was building an entire working website from scratch—seeing my concepts come to life was incredibly rewarding. If I had more time, I'd like to explore more advanced JavaScript frameworks and animation methods to further bring interactivity and glare into my designs.

## Skills Application
Beyond the classroom, I've planned to use my web development skills to create personal projects,for example: help local charities build basic websites. I intend to continue applying these skills to create real-world and efficient digital solutions.

## Future Learning
I would like to learn responsive design more comprehensively, learn React or Vue frameworks, and transition into backend development to be a full-stack web developer. UX/UI design principles learning in depth is also in the pipeline.

## Advice for Beginners
My advice to beginners is to keep trying and be patient. Web design is challenging, but constant practice and curiosity will lead to improvement. Don't hesitate to seek help from the community and always test with real users to understand their needs.
