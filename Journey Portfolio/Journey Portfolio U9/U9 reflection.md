# 📝 Reflection on Unit 9: Introduction to JavaScript

## Lesson 1 – What is JavaScript and Why is it Important?

In this lesson, I learned that JavaScript is a powerful scripting language that enables interactivity in web development. Unlike HTML and CSS which handle structure and style, JavaScript allows users to interact with web pages through events like clicks, input, and real-time updates. I now understand why JavaScript is essential for dynamic websites, and how it brings life to otherwise static pages.

## Lesson 2 – Basics of JavaScript: Input and Output

This lesson introduced the basic syntax and functionality of JavaScript. I practiced using `alert()`, `prompt()`, and `console.log()` to communicate with users and display data. I also began learning how to define variables and use user input to affect what happens on the page. One key takeaway was how JavaScript reads and responds to user interaction in real-time.

## Lesson 3 – JavaScript and HTML

This was a hands-on lesson that focused on integrating JavaScript with HTML. I learned how to find HTML elements using `getElementById()` and how to modify them dynamically with `.textContent`. I also created buttons and attached JavaScript functions using the `onClick` attribute. This helped me understand how JavaScript works with the DOM (Document Object Model) to make websites interactive.

## Personal Reflection

Before starting Unit 9, JavaScript seemed complicated. Now, I feel more confident writing simple scripts and connecting them to HTML elements. I especially enjoyed seeing how just a few lines of code can change how a webpage looks and behaves.
