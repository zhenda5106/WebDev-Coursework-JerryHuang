# Unit 3 Reflection: Client Project

## Key Takeaways:
- **Client Web Page Project**: Learned to translate client needs into web design goals. Practiced balancing creativity with practical constraints like deadlines and requirements.  
- **Interviewing Your Client**: Discovered the importance of asking open-ended questions to uncover deeper needs (e.g., "What problem do you want this website to solve?").  

## Challenges:

- Managing expectations when client requests conflict with technical feasibility.（really important, because of that we always have to think about the difference about reality and requirements）
