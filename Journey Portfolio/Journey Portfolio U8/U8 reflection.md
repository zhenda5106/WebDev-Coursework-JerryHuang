# Reflection on Unit 8 – Advanced CSS and Responsive Design

## What I Learned

In **Unit 8**, I explored advanced CSS techniques and how to build modern, responsive web layouts. This unit was divided into four key lessons:

### Lesson 1: Style Using `div` and `class`
I learned how to structure HTML content using `<div>` elements and how to apply CSS styling using class selectors. This helped me build cleaner, more maintainable code, and gave me more control over styling.

### Lesson 2: The Box Model and Positioning
This lesson deepened my understanding of the **CSS box model**, including `margin`, `border`, `padding`, and `content`. I also learned how to position elements using `static`, `relative`, `absolute`, and `fixed`. This was essential in creating layouts that behave predictably.

### Lesson 3: The Display Property and Positioning Classes
I discovered how the `display` property (like `block`, `inline-block`, `flex`, and `none`) affects layout. Using positioning classes gave me reusable tools to control layout across the site.

### Lesson 4: Responsive vs. Adaptive Design
This was the most eye-opening lesson. I learned the difference between **responsive design** (fluid, flexible) and **adaptive design** (layout changes at specific breakpoints). I practiced using media queries to create websites that look great on both desktop and mobile devices.

## My Takeaway

The biggest takeaway from this unit is that a well-designed website must look good and work well on **all screen sizes**. I now feel more confident in using advanced CSS to build layouts that are not only visually appealing but also **user-friendly** and **adaptive to various devices**.
